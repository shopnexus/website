## Development

When starting the dev server, use background mode:

```
astro dev --background
```

Manage the background server with `astro dev stop`, `astro dev status`, and `astro dev logs`.

## Design

Read `DESIGN.md` before building UI. Use only the utilities from `src/styles/tokens.css`; Tailwind's default colours, type steps, radii and breakpoints are switched off. The Android app's `app/.superdesign/design-system.md` is the reference for anything `DESIGN.md` leaves out.

ShopNexus holds no money: the only deal path is cash on delivery with inspection at the door. No page may mention escrow, a wallet, or a refund from the platform.
