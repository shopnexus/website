# Components

The website was scaffolded on 2026-11-04 and has no shared UI components yet.
Framework: Astro 7 (SSR, Node adapter) with React 19 islands. Styling:
Tailwind 4 through `@tailwindcss/vite`, with tokens in `src/styles/tokens.css`.
Icons: Material Symbols Rounded through unplugin-icons
(`~icons/material-symbols/<name>-rounded`). No component library.

The Android app's components (listing card, filter chips, search bar, grouped
list, offer sheet) are described in `app/.superdesign/design-system.md` and are
the reference for the web versions.
